# 💱 Currency Converter (PS No. 35)

A Python-based command-line Currency Converter application developed as part of the academic coursework at **Rungta International Skills University**.

## 📌 Project Overview
The program converts amounts between supported currencies using **INR** as the base currency. It calculates values based on fixed exchange rates and formats the output rounded to two decimal places, along with complete input validation.

## 🚀 Features
* **Supported Currencies:** `INR`, `USD`, `EUR`, `GBP`
* **Base Currency Approach:** Converts any currency to INR first, then to the target currency.
* **Input Validation:** Handles invalid numbers, negative amounts, and unsupported currency codes gracefully.
* **Formatted Output:** Rounds converted amounts to 2 decimal places.

## 🛠️ How to Run
1. Ensure **Python 3.x** is installed on your system.
2. Clone or download this repository.
3. Open Terminal / PowerShell in the project directory.
4. Run the script using:
   ```bash
   python currency_converter.py
   ```
